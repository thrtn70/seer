Seer 0.2.0

The first update since 0.1.0, and the release that makes every future update painless.

Settings

  • A proper Settings window, with General, Apps, Suggestions and Style tabs.
  • Per-app control: pause Seer in the apps where you don't want it, and it stays paused.
  • Tune suggestion length, how eagerly Seer offers one, and how the ghost text looks.

Menu bar

  • Status at a glance, with how many suggestions you accepted this session.
  • When Seer isn't running yet, the menu now tells you exactly what it's waiting for.

Style

  • Seer learns how you write and leans that way in its suggestions.
  • Everything it learns stays on your Mac, encrypted. From the Style tab you can see what it picked up, pin any part of it by hand, export it, or erase it.

Updates

  • Seer updates itself now. Check any time from the menu bar.
  • The language model has moved out of the app: it downloads once on first run and is verified before it's used. Updates are a few megabytes instead of a gigabyte, and they never re-download a model you already have.

Requires an Apple Silicon Mac on macOS 14 or later. Still entirely offline — nothing you type leaves your Mac.
